# 個人資產 APP — 交接與待辦（更新：2026-11-20）

## 專案概況
- 位置：`C:\Users\bigbe\Desktop\個人資產APP`；線上網址：https://personal-asset-app.web.app（Firebase 專案 `personal-asset-app`）
- 技術：React + TypeScript + Vite + Tailwind + Recharts，PWA；Firebase Auth（Google／Email）＋ Firestore（asia-east1，Spark 免費方案，不綁卡）
- 同步：本機 Dexie 完整副本 + 增量同步（updatedAt）+ 樂觀鎖（version）+ 刪除標記；`src/sync/`
- 所有數字（餘額、持股、損益、曲線）都由紀錄即時計算，刪除紀錄＝校正回歸；計算邏輯在 `src/domain/`，有 54 個 Vitest 單元測試
- 股價：瀏覽器直接讀 FinMind（上市＋上櫃），失敗時用證交所官網；存 Firestore `prices/` 共用；除息資料用 FinMind `TaiwanStockDividend`
- 使用者：管理者＝`config/allowlist` 的 Email；其他人用邀請碼加入（`members/`、`invites/`）；設定頁可刪除帳號
- 設定頁最下方有自動版本號（建置時的台灣時間，例如 v2026.10.12.0129）

## 重要決定（已完成）
- 持股以「券商帳戶＋股票代號」分開計算；成本法預設平均、可切先進先出（先進先出時逐筆估算賣出成本，個股頁有明細表）
- 含息成本開關（股利從除息日前持股的成本扣掉）；現金股利有除息日（自動帶入）、入帳手續費
- 手續費＝成交價金 × 0.1425% × 折扣，無條件捨去，零股最低 1、整股最低 20；成交價金也捨去到元
- 永豐是全額收費、月底退佣：券商折扣設 10 折，退佣記成「理財 › 手續費退佣」收入
- T+2 只跳過週六日；帳戶紀錄裡顯示已交割的「證券交割」（依交割日合併）與股利入帳
- 淨資產：買賣股票的交割款在成交日就扣（避免 T+2 期間現金和股票重複計算）；帳戶餘額本身在交割日才扣
- 轉帳手續費由轉出帳戶負擔，算進支出；轉帳在收支統計頁、以及同帳戶子帳戶互轉在帳戶頁，都用灰色不加正負號
- 外幣不換算，依幣別另外列出

## 工作方式
- 先討論、確認後才動手；解釋和選項用一般文字列出（選項視窗會擋住說明），用繁體中文回覆
- 使用者的 PowerShell 會擋 `npx.ps1`，請用 `npm.cmd`／`npx.cmd`
- 修改流程：開分支 → 修改 → `npm.cmd test` → `npm.cmd run build`（含 tsc）→ 推送並開 PR → 使用者同意後合併進 `main` → 使用者同意後才部署（`npm.cmd run deploy`）
- 修改 `firestore.rules` 後要另外部署：`npx.cmd firebase deploy --only firestore:rules`（需使用者同意）
- 手機上的 APP 要「打開一次 → 完全滑掉 → 再打開」才會更新；用設定頁的版本號確認
- 退回方式：線上版本到 Firebase 控制台 → Hosting → 版本記錄按「復原」；程式碼用 `git revert -m 1 <合併提交>`

## 待辦清單（都還沒動手，等使用者決定）

### A. 功能與顯示
1. **個股頁比照永豐排列**：大字改成「預估損益／報酬率」，同時顯示「市值」（股數 × 現價）和「現值」（扣預估賣出成本後）。選項：A 比照永豐（推薦）／B 只加「市值」標籤並補上現值／C 維持現狀；投資頁持股列表要不要一起改也待定
2. **帳戶列表看不到待交割款**：券商帳戶那一列只顯示帳面餘額。可以加一行小字「可用 65,000（待交割 −35,000）」
3. **已封存帳戶仍算進「所有帳戶合計」**：要不要排除，或在合計旁邊註明
4. **已封存帳戶不能轉帳**（記帳、轉帳、股票、還款的帳戶選單都不會出現）。選項：A 封存時若有餘額，先要求選一個帳戶自動轉出再封存（推薦）／B 已封存帳戶只允許當「轉出」帳戶／C 維持現狀，需要時先取消封存
5. **同一天有買有賣（非當沖）的順序**：先進先出在同一天是看記錄先後。可選擇加「成交時間」欄位，或只在手冊提醒
6. **收入支出的分類圖示**：每個分類加一個小圖示，讓版面可愛一些
7. **負債攤還表**（原計畫的之後版本）
8. **更新使用手冊**（`docs/使用手冊.pdf`）：加入含息成本、除息日、逐筆明細、股利／轉帳手續費、手續費退佣、證券交割紀錄、依券商分開、試算不同提示、版本號與「開兩次才更新」，以及之後新增的功能
