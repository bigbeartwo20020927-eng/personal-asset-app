# 個人資產 APP — 交接與待辦（2026-10-21）

## 專案概況
- 位置：`C:\Users\bigbe\Desktop\個人資產APP`；線上網址：https://personal-asset-app.web.app（Firebase 專案 `personal-asset-app`）
- 技術：React + TypeScript + Vite + Tailwind + Recharts，PWA；Firebase Auth（Google／Email）＋ Firestore（asia-east1，Spark 免費方案，不綁卡）
- 同步：本機 Dexie 完整副本 + 增量同步（updatedAt）+ 樂觀鎖（version）+ 刪除標記；`src/sync/`
- 所有數字（餘額、持股、損益、曲線）都由紀錄即時計算，刪除紀錄＝校正回歸；計算邏輯在 `src/domain/`，有 51 個 Vitest 單元測試
- 股價：瀏覽器直接讀 FinMind（上市＋上櫃），失敗時用證交所官網；存 Firestore `prices/` 共用；除息資料用 FinMind `TaiwanStockDividend`
- 使用者：管理者＝`config/allowlist` 的 Email；其他人用邀請碼加入（`members/`、`invites/`）；設定頁可刪除帳號
- 設定頁最下方有自動版本號（建置時的台灣時間，例如 v2026.10.12.0129）

## 重要決定（已完成）
- 持股以「券商帳戶＋股票代號」分開計算；成本法預設平均、可切先進先出（先進先出時逐筆估算賣出成本，個股頁有明細表）
- 含息成本開關（股利從除息日前持股的成本扣掉）；現金股利有除息日（自動帶入）、入帳手續費
- 手續費＝成交價金 × 0.1425% × 折扣，無條件捨去，零股最低 1、整股最低 20；成交價金也捨去到元
- 永豐是全額收費、月底退佣：券商折扣設 10 折，退佣記成「理財 › 手續費退佣」收入
- T+2 只跳過週六日；帳戶紀錄裡顯示已交割的「證券交割」（依交割日合併）與股利入帳
- 轉帳手續費由轉出帳戶負擔，算進支出
- 外幣不換算，依幣別另外列出

## 工作方式
- 先討論、確認後才動手；解釋和選項用一般文字列出（選項視窗會擋住說明），用繁體中文回覆
- 使用者的 PowerShell 會擋 `npx.ps1`，請用 `npm.cmd`／`npx.cmd`
- 改完：`tsc` → 測試 → `npm run build` → 啟動開發伺服器並確認模組是最新版本 → 使用者在 http://localhost:5173 測試 → 使用者同意後才部署（`npx firebase deploy --only hosting`）
- 修改 `firestore.rules` 後要另外部署：`npx firebase deploy --only firestore:rules`（需使用者同意）
- 手機上的 APP 要「打開一次 → 完全滑掉 → 再打開」才會更新；用設定頁的版本號確認
